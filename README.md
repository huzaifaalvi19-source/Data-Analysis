## Pizza sales dashboard

An Excel analysis of 2015 pizza orders, covering product mix, revenue patterns, and ordering behavior.

**Approach**
1. Combine order and product information using lookup functions.
2. Calculate sales and supporting analysis fields.
3. Summarize performance using pivot tables and charts.
4. Explore patterns through dashboard filters and slicers.

**Questions explored:** category demand, revenue by size, peak ordering times, monthly sales, and premium versus standard product mix.

**Tools:** Microsoft Excel · VLOOKUP · calculated fields · pivot tables · charts · slicers

## RFM customer segmentation

RFM groups customers using **recency** (how recently they bought), **frequency** (how often they bought), and **monetary value** (how much they spent).

The documented approach aggregates transactions by customer, applies percentile-based scores, and maps customers to segments such as Champions, Potential Loyalists, New Customers, and At-Risk Customers.

The repository currently links to an **externally hosted dataset**. A standalone RFM analysis workbook, Python notebooks, SQL scripts, and Power BI files are not currently uploaded here.
